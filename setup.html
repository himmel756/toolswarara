Cowork と Claude Code の初期設定（Windows）v1.1

新しいPCで使い始めるときの手順メモです。コマンドは右の「コピー」でそのまま貼り付けられます。

はじめに確認 Cowork Claude Code 困ったとき

準備用バッチ（claude_app_setup.bat）

ダブルクリックするだけで「仮想マシン プラットフォーム」の確認・有効化と、Git のインストールをまとめて行います。途中で管理者の許可を求められたら「はい」を選んでください。

「WindowsによってPCが保護されました」と出た場合は「詳細情報」→「実行」で進めます。

ダウンロード

はじめに確認すること

Coworkが選べない・起動しないときは、まずここを確認します。

項目必要な条件
プラン有料プラン（Pro / Max / Team / Enterprise）のアカウントでログインしていること
インストール方法claude.com/download から入れた最新版（.msix版）であること。古い.exe版ではCoworkが使えません
管理者権限インストール時に管理者権限があること。権限なしで入れた場合、デスクトップのCoworkは使えません
仮想マシン プラットフォームWindowsの機能「仮想マシン プラットフォーム」が有効であること（有効化後は再起動が必要）
その他Sモードのパソコンでは使えません

対応チェックツール：公式ヘルプ（Claude Cowork の使い方）から、PCがCoworkに対応しているか確認する小さなプログラムをダウンロードできます。「This computer is ready for Cowork」と出れば準備OKです。

Cowork の初期設定

デスクトップアプリで使います。Web・スマホ版はベータとして順次提供中です。

  1. デスクトップアプリを入れる

    公式サイトからWindows版をダウンロードしてインストールします。すでに入っている場合は最新版に更新します。

    https://claude.com/download

  2. 仮想マシン プラットフォームを有効にする

    Coworkを選んだときに「追加のセットアップが必要」や「HCSサービスがない」といった表示が出たら、この機能が無効です。準備用バッチ（claude_app_setup.bat）を実行するか、下の「PowerShell便利コマンド」で有効にして再起動します。

  3. 有料プランのアカウントでログイン

    別のアカウントや無料アカウントだとCoworkが表示されません。

  4. 入力欄で「Cowork」に切り替える

    メッセージ入力欄のところにある「Chat / Cowork」の切り替えで「Cowork」を選び、やってほしい作業を書きます（アプリのバージョンによって表示位置が少し違います）。見当たらない場合はアプリを更新してください。

  5. 作業フォルダを指定する

    Claudeが読み書きしてよいフォルダを選びます。最初は作業用の専用フォルダを作っておくと安心です。

  6. 共通の指示を設定（任意）

    「設定 → Cowork」の「グローバル指示」で、毎回使う指示（口調、出力の形式など）を登録できます。

ポイント：デスクトップのCoworkは、作業中アプリを開いたままにしてPCがスリープしないようにしてください。初回起動時は作業環境のダウンロードで少し時間がかかります。

Claude Code（アプリの Code タブ）の初期設定

デスクトップアプリにClaude Codeが含まれているので、別途インストールは不要です。Windowsで必要な準備はGitだけです。

  1. Git for Windows を入れる

    WindowsでPC上のフォルダを使うにはGitが必要です。準備用バッチで自動で入ります。手動の場合はPowerShellで次を実行します。

    winget install --id Git.Git -e

  2. アプリを再起動する

    Gitを入れたあとは、Claudeアプリを一度終了して開き直します。

  3. Code タブを開く

    アプリ上部中央の「Code」を選びます。

  4. 作業フォルダを選んで依頼する

    使うフォルダを選んで、やってほしいことを書きます。最初は確認ありのモードなので、Claudeが提案した変更を見てから適用できます。

  5. 細かい設定・更新（任意）

    動作の設定は「設定 → Claude Code」、アプリの更新は「ヘルプ → アップデートを確認」から行います。

Codeタブが使えないとき：Claude Codeは有料プランが必要です（無料プランでは使えません）。Gitを入れたあと、アプリを再起動したかも確認してください。

PowerShell 便利コマンド

準備用バッチでまとめて実行できますが、個別に使う場合はこちら。どれも「管理者として実行」したPowerShellで使います。

  1. 仮想マシン プラットフォームの状態を確認

    「State : Enabled」なら有効です。

    Get-WindowsOptionalFeature -Online -FeatureName VirtualMachinePlatform

  2. 仮想マシン プラットフォームを有効にする

    実行後、PCを再起動します。

    Enable-WindowsOptionalFeature -Online -FeatureName VirtualMachinePlatform -All

  3. 「VM service not running」と出たとき

    Coworkの仮想マシン用サービスを起動します。直らない場合は claude.com/download から入れ直します（Microsoft Store版はサービス名が CoworkVMServiceStore です）。

    sc.exe start CoworkVMService

補足：VMwareやVirtualBoxを使っているPCでは、Windowsの仮想化機能と競合して起動しないことがあります。ストレージの保存先（設定 → システム → ストレージ）がDドライブになっているとエラーになることもあるので、Cドライブにしておくと安心です。
